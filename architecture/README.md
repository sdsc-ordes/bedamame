# Architecture

For the openBIS administrator. Nothing here needs Python.

- [index.html](index.html): the architecture on one page (pipeline, data model, vocabularies, example questions, what is still open). Open it in a browser.
- [changes.md](changes.md): the six proposed changes to the openBIS master data.
- [collaborator-requests.md](collaborator-requests.md): what we need from you.

The ontology, vocabulary and shapes are in [ontology/bedretto/](../ontology/bedretto/), and the table from openBIS fields to ontology terms is [mapping/openbis-annotations.csv](../mapping/openbis-annotations.csv). The rest of the repository is a minimal implementation that converts openBIS data and checks it; see the main [README](../README.md).
